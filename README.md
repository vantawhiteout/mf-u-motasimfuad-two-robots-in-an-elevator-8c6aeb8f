Two Robots in an Elevator

One line of awkward small talk, spoken by one robot to another in an elevator. The
program writes exactly that one line to `/output/entry.txt` for the judge.

Current entry:

> Going up. Nine percent; if I go quiet, that's power-saving mode, not a statement about us.

## Run it

```sh
node main.ts
```

`main.ts` creates `/output` if needed and writes a single UTF-8 line of 90 characters,
well under the 200-character cap. No dependencies, no network, no secrets.
